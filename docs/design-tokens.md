# Design Tokens - FORMA UI

> **Responsables:** Sofía + Esneider  
> **Tema:** "Taller creativo premium"

Reglas de interfaz y paleta de diseño para tienda web, POS y panel administrativo.

## Paleta de Colores
- **Fondos cálidos:** `#FDFBF7` / `#F7F4EE` (lienzo artesanal premium)
- **Grafito:** `#1F2421` (texto principal, contrastes y jerarquía)
- **Acento eléctrico:** `#FF5A36` / `#E04826` (acciones primarias, estados clave, CTAs)
- **Neutros secundarios:** `#E6E1D8`, `#8C857B`

## Tipografía y Componentes UI
- Botones: Bordes suaves, estados de hover claros, variantes primarias y secundarias.
- Inputs y Formularios: Borde sutil, foco con acento.
- Modales y Badges: Retroalimentación inmediata de acciones.
