# Matriz de Pruebas QA - FORMA POS

> **Responsable:** Thomas  
> **Propósito:** Casos de prueba y checklist para la demo

## Checklist de Demo

### 1. Tienda Pública (Store)
- [ ] Visualización de catálogo de productos personalizados.
- [ ] Selección y combinación de opciones de personalización.
- [ ] Flujo de checkout web y generación de referencia de pedido.
- [ ] Consulta de tracking de pedido por código de seguimiento.

### 2. Punto de Venta (POS)
- [ ] Carrito presencial ágil con búsqueda de productos.
- [ ] Registro de pago inmediato o anticipo (anticipo mínimo configurable).
- [ ] Emisión de comprobante con referencia única.

### 3. Panel de Administración (Admin)
- [ ] Dashboard KPI con métricas de ventas y pedidos por estado.
- [ ] Cambio de estados de preparación y entrega.
- [ ] Gestión de promociones y cupones no acumulables.
- [ ] Control de usuarios y roles (ADMIN, SUPERVISOR, VENDEDOR, PREPARADOR).
